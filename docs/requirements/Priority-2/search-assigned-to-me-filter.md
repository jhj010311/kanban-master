# Priority 2 요구사항 – Search "Assigned to Me" Filter

## 목적

칸반 보드의 검색 기능을 확장하여 사용자가 **자신에게 할당된 카드만을 빠르게 필터링**할 수 있도록 한다. 이를 통해 사용자는 자신의 작업 현황을 즉시 파악하고 생산성을 향상시킬 수 있다.

## 범위

- **포함**: SearchPanel 컴포넌트에 "내게 할당됨" 필터 버튼 추가, 현재 로그인 사용자의 인증 정보 활용, 다른 필터와의 조합 지원.
- **제외**: 백엔드 API 수정(이미 assignees 필터 구현됨), 담당자 자동 완성 기능, 다중 담당자 선택 UI.

## 이해관계자

### 사용자 페르소나

1. **팀 멤버 (김개발)**
   - 역할: 소프트웨어 개발자
   - 니즈: 자신에게 할당된 작업 카드를 빠르게 찾아 진행 상황을 확인
   - 시나리오: 매일 아침 출근 후 오늘 해야 할 작업들을 한눈에 파악

2. **프로젝트 매니저 (박관리)**
   - 역할: 프로젝트 관리자
   - 니즈: 특정 팀원에게 할당된 작업 현황을 확인하여 업무 분담 조정
   - 시나리오: 팀원별 작업 부하를 체크하고 추가 작업 할당 결정

3. **디자이너 (이디자)**
   - 역할: UI/UX 디자이너
   - 니즈: 디자인 검토 요청이 온 카드들을 빠르게 필터링
   - 시나리오: 여러 보드에 걸쳐 자신에게 할당된 디자인 작업 확인

## UX·인터랙션 요구사항

### 사용자 플로우

1. **검색 패널 열기**: 사용자가 보드 상단의 검색 버튼을 클릭하여 SearchPanel을 연다.
2. **필터 영역 확장**: "🔍 필터" 버튼을 클릭하여 필터 옵션 영역을 표시한다.
3. **"내게 할당됨" 선택**: 상태 필터 섹션에서 "내게 할당됨" 버튼을 클릭한다.
   - 버튼의 배경색과 테두리가 변경되어 선택 상태를 표시한다.
   - 필요 시 다른 필터(우선순위, 라벨 등)도 함께 선택한다.
4. **검색 실행**: "검색" 버튼을 클릭한다.
5. **결과 확인**: 현재 사용자에게 할당된 카드만 검색 결과 그리드에 표시된다.
6. **카드 선택**: 원하는 카드를 클릭하여 상세 정보를 확인하거나 해당 보드로 이동한다.

### 시각적 피드백

- **미선택 상태**: 연한 파스텔 배경색, 얇은 테두리, 부드러운 hover 효과
- **선택 상태**: 진한 파스텔 배경색, ring 효과, 글자 색상 변경
- **버튼 디자인**: 기존 "완료", "미완료", "지연됨" 버튼과 동일한 스타일 체계 적용

### 접근성 고려사항

- 버튼에 명확한 aria-label 속성 제공 (예: "내게 할당된 카드만 보기")
- 키보드 Tab 키로 포커스 이동 가능
- Enter 또는 Space 키로 토글 가능
- 포커스 링을 시각적으로 표시하여 키보드 사용자 지원

## 제약사항

### 기술 제약

- **프론트엔드 전용 수정**: 백엔드 API는 이미 assignees 필터를 지원하므로 수정하지 않는다.
- **프레임워크**: React 19, TypeScript 사용 필수.
- **스타일링**: Tailwind CSS 파스텔 디자인 시스템 준수.
- **인증 훅**: 기존 `useAuth()` 훅을 활용하여 현재 사용자 정보를 가져온다.

### 비즈니스 제약

- **assignee 필드 타입**: 현재 Card 엔티티의 assignee 필드는 User ID가 아닌 **사용자 이름(String)**을 저장한다.
- **이름 중복 가능성**: 동일한 이름을 가진 사용자가 여러 명 존재할 경우 의도하지 않은 카드가 검색될 수 있다. (향후 User ID 기반으로 개선 필요)
- **대소문자 구분**: 백엔드의 assignee 필터는 대소문자를 정확히 일치시켜 검색한다.

### 데이터 제약

- **null 값 처리**: assignee 필드가 null인 카드는 검색 결과에서 제외된다.
- **빈 문자열 처리**: assignee가 빈 문자열인 경우도 null과 동일하게 처리된다.

## 용어 정리

| 용어 | 정의 |
|------|------|
| **카드 (Card)** | 칸반 보드에서 하나의 작업 항목을 나타내는 기본 단위. 제목, 설명, 담당자, 우선순위, 라벨 등의 속성을 가진다. |
| **할당 (Assign)** | 특정 카드의 담당자를 지정하는 행위. 카드의 assignee 필드에 사용자 이름을 설정한다. |
| **담당자 (Assignee)** | 카드를 수행할 책임이 있는 사용자. 현재는 사용자 이름(String)으로 식별된다. |
| **검색 필터 (Search Filter)** | 특정 조건에 맞는 카드만을 표시하기 위한 조건 설정 기능. 키워드, 우선순위, 라벨, 상태 등 여러 조건을 조합할 수 있다. |
| **내게 할당됨 (Assigned to Me)** | 현재 로그인한 사용자가 담당자로 지정된 카드를 의미한다. |
| **상태 필터 (Status Filter)** | 카드의 완료 여부(isCompleted), 지연 여부(overdue) 등을 기준으로 필터링하는 조건. |
| **우선순위 (Priority)** | 카드의 중요도를 나타내는 속성. HIGH, MEDIUM, LOW 세 가지 값 중 하나를 가진다. |
| **라벨 (Label)** | 카드를 분류하고 시각적으로 구분하기 위한 색상 태그. 여러 개의 라벨을 하나의 카드에 적용할 수 있다. |
| **SearchPanel** | 카드 검색 UI를 제공하는 React 컴포넌트. 검색어 입력, 필터 선택, 결과 표시 기능을 포함한다. |
| **CardSearchRequest** | 검색 조건을 서버로 전달하기 위한 데이터 구조. keyword, priorities, assignees, labelIds, isCompleted, overdue 등의 필드를 포함한다. |
| **CardSearchResult** | 검색 결과로 반환되는 카드 정보. 카드의 기본 정보 외에 boardName, columnName 등의 컨텍스트 정보도 포함한다. |
| **파스텔 색상 체계** | 프로젝트에서 사용하는 부드러운 색상 팔레트. pastel-blue, pastel-pink, pastel-green 등의 Tailwind CSS 커스텀 색상을 포함한다. |

## 구현 참고 사항

### 기존 구현 현황

- **백엔드 검색 API**: `GET /api/v1/search/boards/{boardId}/cards` 엔드포인트가 이미 구현되어 있으며, 다음 쿼리 파라미터를 지원한다.
  - `keyword`: 검색 키워드 (제목, 설명)
  - `priorities`: 우선순위 필터 (다중 선택 가능)
  - `assignees`: 담당자 이름 필터 (다중 선택 가능) ← **이미 구현됨**
  - `labelIds`: 라벨 ID 필터 (다중 선택 가능)
  - `isCompleted`: 완료 상태 필터
  - `dueDateFrom`, `dueDateTo`: 마감일 범위 필터
  - `overdue`: 지연 여부 필터

- **프론트엔드 검색 서비스**: `searchService.ts`에서 assignees 파라미터를 URL 쿼리 스트링에 추가하는 로직이 이미 구현되어 있다.

- **타입 정의**: `types/search.ts`에 `CardSearchRequest` 인터페이스의 `assignees?: string[]` 필드가 이미 정의되어 있다.

### 인증 정보 활용 방법

- **프론트엔드**: AuthContext의 `useAuth()` 훅을 통해 현재 로그인한 사용자 정보(`user.name`)를 가져온다.
- **백엔드**: `@AuthenticationPrincipal` 어노테이션을 통해 현재 인증된 User 객체에 접근할 수 있다. (이번 작업에서는 백엔드 수정 불필요)

### API 엔드포인트 형식

```
GET /api/v1/search/boards/{boardId}/cards?assignees={userName}
```

- **요청 예시**: `/api/v1/search/boards/123/cards?assignees=김개발&priorities=HIGH&isCompleted=false`
- **응답 형식**: `CardSearchResult[]` 배열 (JSON)

### UI 컴포넌트 배치

SearchPanel 컴포넌트의 필터 영역 구조:
1. 키워드 입력창 (최상단)
2. 우선순위 필터 버튼 (HIGH, MEDIUM, LOW)
3. 라벨 필터 버튼 (보드별 라벨 목록)
4. **상태 필터 버튼** (완료, 미완료, 지연됨, **← 여기에 "내게 할당됨" 추가**)
5. 필터 초기화 버튼 (우측 정렬)

## 미해결 이슈

1. **User ID 기반 시스템으로의 마이그레이션**: 현재 assignee 필드는 사용자 이름(String)을 저장하므로 동명이인 문제가 발생할 수 있다. 향후 User ID 기반으로 전환하는 것을 검토해야 한다.

2. **이름 변경 시 데이터 일관성**: 사용자가 이름을 변경할 경우 기존 카드의 assignee 필드 값과 불일치가 발생할 수 있다. 마이그레이션 전략이 필요하다.

3. **"담당자 선택" 필터 확장**: 현재는 "내게 할당됨"만 제공하지만, 향후 특정 팀원을 선택할 수 있는 드롭다운 필터로 확장할 가능성을 고려해야 한다.

4. **다중 담당자 지원**: 현재 Card 엔티티는 단일 담당자만 지원하지만, 향후 다중 담당자 기능이 추가될 경우 검색 필터도 함께 업데이트되어야 한다.

5. **워크스페이스 전체 검색**: 현재는 보드별 검색만 지원하지만, 워크스페이스 전체에서 내게 할당된 카드를 검색하는 기능도 유용할 수 있다. (별도 API 엔드포인트 이미 존재: `GET /api/v1/search/workspaces/{workspaceId}/cards`)
